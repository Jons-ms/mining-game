# mining-game

## Спільний курс CRYP

Поточний курс і стан його зміни зберігаються в документі Firestore `market/exchangeRate`. Клієнти підписуються на цей документ, а транзакція Firestore просуває курс для всіх гравців.

У Firebase Console правила Firestore мають дозволяти автентифікованим гравцям читати та оновлювати цей документ. Додай відповідний дозвіл до наявних правил, зберігши їхні інші умови:

```text
match /market/exchangeRate {
  allow read, write: if request.auth != null;
}
```

Це дозволяє будь-якому авторизованому клієнту змінювати спільний курс. Для гри, де важливо захистити економіку від підміни, перенеси запис курсу у Cloud Function і заборони клієнтам прямий запис.
