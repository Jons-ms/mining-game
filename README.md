# mining-game

## Індивідуальний курс CRYP

Курс кожного гравця та стан його зміни зберігаються в полі `market` його документа Firestore: `players/{uid}`. Тому курс не залежить від інших гравців, але синхронізується між пристроями, де власник увійшов у той самий акаунт.

Для цього підходять наявні правила, які дозволяють гравцю читати й змінювати лише власний документ `players/{uid}`. Окреме правило для колекції `market` не потрібне. Якщо курс недоступний, перевір, що чинні правила Firestore дозволяють користувачу читати та змінювати його документ гравця.

Запис курсу виконується клієнтською транзакцією. Гравець може змінити власний курс через браузер; якщо це потрібно обмежити, перенеси оновлення курсу у Cloud Function.
