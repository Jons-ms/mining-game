# mining-game

## Спільний курс CRYP

У грі є один курс CRYP для всіх гравців. Він і стан його зміни зберігаються в окремому документі Firestore: `market/exchangeRate`.

Кожен відкритий клієнт підписується на цей документ. Коли курс оновлюється, усі гравці отримують нове значення. Оновлення виконується транзакцією Firestore, тому кілька відкритих клієнтів не створюють різні курси.

Додай до чинних правил Firestore цей блок усередині `match /databases/{database}/documents`:

```text
match /market/exchangeRate {
  allow read, write: if request.auth != null;
}
```

Правило дає авторизованим гравцям доступ до спільного курсу. Якщо потрібно не дозволяти гравцям змінювати курс вручну, лиши клієнтам `allow read` і перенеси його оновлення у Cloud Function.
