# CRYP Mining

Браузерна гра з Firebase Auth та збереженням прогресу в Cloud Firestore.

## Спільні курси

Курс CRYP і стан його зміни зберігаються у `market/exchangeRate`. Курс Blue має окремий документ `market/blueExchangeRate`, стартує з 4,25 ₴ і обмежений діапазоном 4,25–13,75 ₴ правилами Firestore. Клієнти підписуються на кожен документ окремо та оновлюють відповідний курс транзакцією раз на 5 секунд.

Blue зберігається окремо від CRYP у документі гравця. Старі збереження під час нормалізації отримують баланс Blue 0; наявні гривні, CRYP, карти та поля ферми зберігаються.

Майнінг Blue дають лише встановлені Blue-карти: RTX 4060 (2 400 ₴, 0,015 Blue/с), RTX 3070 (10 000 ₴, 0,06 Blue/с), RTX 4070 (15 000 ₴, 0,08 Blue/с). Курс Blue відображається з двома десятковими знаками.

## Рейтинг «Подіум»

Подіум показує до десяти гравців за формулою:

`баланс гривень + баланс CRYP × курс CRYP + баланс Blue × курс Blue`

Коли гравець входить у гру та зберігає прогрес, його клієнт оновлює власний публічний документ у колекції `podiumPlayers`. Сторінка рейтингу читає ці публічні рядки й обчислює топ-10 на пристрої за поточним спільним курсом. Коли новий гравець заходить або зберігає гру, відкриті сторінки отримують оновлення через Firestore.

Для цього варіанта не потрібні Cloud Functions, Cloud Scheduler, GitHub Actions чи окреме налаштування Google Cloud IAM. Потрібні лише Firebase Auth і вже створена Firestore база.

## Правила Firestore

Додай правило для власного публічного рядка рейтингу всередині `match /databases/{database}/documents`:

```text
match /podiumPlayers/{playerId} {
  allow read: if request.auth != null;
  allow create, update, delete: if request.auth != null && request.auth.uid == playerId;
}
```

Воно дає авторизованим гравцям змогу читати публічні рядки Подіуму, а кожному гравцеві — змінювати лише власний рядок. Приватні документи `players/{uid}` і далі доступні тільки їхнім власникам. Правило курсу Blue додатково перевіряє діапазон і формат документа. Застосуй оновлені правила з файлу `firestore.rules` у Firebase Console.

## Оновлення та точність

Рейтинг оновлюється, коли гравці заходять у гру або зберігають прогрес; якщо ніхто не заходить, нових даних не з’явиться. Баланси й економічні дії виконуються на клієнті, а власник може записати свій документ `players/{uid}`. Це підходить для дружньої гри, але не захищає економіку від накрутки. Правило Blue гарантує межі курсу й формат документа; авторизований клієнт усе ще може записати довільний курс усередині цих меж.
